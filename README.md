# Render Space - Distributed GPU Memory Network

Decentralized render process memory sharing with blockchain integration.

## Features

- **Distributed GPU Memory Sharing**: Share GPU memory regions across network nodes
- **Blockchain Integration**: Immutable record of all render operations
- **High-Precision Timing**: Sub-millisecond refresh rate and timing data
- **Bitcoin Network Linking**: Crypto-ready architecture for decentralized computing
- **Real-Time Data**: Live network statistics and node information
- **Community Driven**: Open source for community collaboration

## Architecture

### GPU Memory Regions
- Direct render process memory access
- Multi-region GPU memory distribution
- Real-time memory sharing protocol

### Blockchain Layer
- Immutable transaction ledger
- Node registration and verification
- Memory share tracking

### Bitcoin Integration
- Decentralized network coordination
- Crypto-address based node identification
- Future payment integration for compute sharing

## Installation

```bash
pip install -r requirements.txt
python render_space_server.py
```

## API Endpoints

- `GET /` - Server status
- `GET /api/gpu-memory` - Get GPU memory regions
- `GET /api/refresh-rate` - Get high-precision timing data
- `POST /api/register-node` - Register a render node
- `GET /api/nodes` - Get all registered nodes
- `GET /api/blockchain` - Get blockchain data
- `POST /api/share-memory` - Share GPU memory with network
- `GET /api/bitcoin-integration` - Bitcoin integration status
- `GET /api/network-stats` - Network statistics
